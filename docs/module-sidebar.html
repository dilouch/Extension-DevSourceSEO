sidebar

Panneau latéral injectable dans n'importe quelle page web. Crée un <iframe> contenant popup.html?mode=sidebar et le positionne à droite ou à gauche. L'ouverture/fermeture est déclenchée par le message TOGGLE_SIDEBAR envoyé depuis popup.js.
